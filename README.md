# shredos_hexview
Hex/ascii viewer for ShredOS

## How To Compile

#### Debian/Ubuntu
```
sudo apt install libncurses-dev
```
#### Fedora / RHEL / CentOS
```
sudo dnf install ncurses-devel
```
#### then
```
gcc shredos_hexview.c -o shredos_hexview -lncurses. 
```
